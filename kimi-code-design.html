🎨 Kimi Code 图标设计方案

仿照 Kimi 风格，融入 Code 元素

📱 原 Kimi 图标参考

方案一：终端光标

保留白色 K 字母，右侧加蓝色闪烁光标，像终端输入状态。右上角保留蓝色星球。

方案二：代码括号

K 字母右侧加一个蓝色斜杠 /，像代码闭合标签。简洁有力，一眼识别出 Code 属性。

方案三：花括号

K 字母被一对蓝色花括号 { } 包裹，程序员最熟悉的符号。星球点上移避免重叠。

方案四：KC 连字

K 为白色主体，C 为蓝色（Code），形成 KC 组合。类似 Google 系产品的字母组合风格。

方案五：等宽字体

K 使用等宽字体（Monospace），下方加蓝色细线像代码下划线。最克制内敛的方案。

方案六：尖括号

<K> 形式，像 HTML/XML 标签。左右尖括号蓝色，K 白色居中。星球点上移。

💡 设计说明

所有方案都保留了 Kimi 的核心视觉元素：
• 🌑 深黑色圆角方形背景（太空/月球暗面意象）
• ✨ 底部银白色星尘粒子（呼应"月之暗面"品牌）
• 🔵 右上角蓝色圆点（蓝色星球/月亮）

变化点在于中间的 K 字母周围加入了代码元素（光标、括号、斜杠、等宽字体等），
既保持与 Kimi 的家族一致性，又清晰传达 "Code" 的产品属性。
